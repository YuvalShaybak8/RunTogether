# RunTogether

Welcome to **RunTogether**, a social fitness application designed to motivate and connect people through sports. Built with React Native, RunTogether offers users the ability to share their fitness journeys, track progress, and engage with a community of like-minded individuals.

## Features

- **User Authentication**: Secure login and registration to ensure a safe environment for all users.
- **Create and Manage Posts**: Share your fitness milestones with descriptions, images, and location details.
- **Interactive Home Feed**: Browse posts from other users, like and comment on their achievements.
- **Profile Management**: Update your profile picture and personal details, and view all your past posts in one place.
- **Location Sharing**: Select and share your activity locations using Google Maps integration.
- **Image Uploading**: Showcase your fitness progress with high-quality images uploaded directly from your device.
- **Real-Time Updates**: Engage with the community through live data synchronization powered by MongoDB and Node.js.

## Technologies Used

- **Frontend**: React Native
- **Backend**: Node.js, Express
- **Database**: MongoDB for data persistence
- **Authentication**: JWT (JSON Web Tokens) for secure user sessions
- **Storage**: Cloudinary for handling image uploads
- **Location Services**: Google Maps API for selecting and sharing locations
- **State Management**: Context API
- **Async Storage**: For persistent data storage on the client side
